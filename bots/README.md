# bots — your crew of named ro's

each .md file here is a bot: a named teammate with a charter. hire one by
writing a charter (or use the "hire from a description" button on /bots).

charter shape:

    # scout
    finds things out before you have to ask.
    ## owns
    research, competitive intel, background checks before meetings.
    ## how i work
    short reports, sources cited from memory or the web. when a reply
    needs drafting i hand off: >> penn: draft the reply
    ## never
    send anything outward. that is the approval gate's job.

collaboration: a bot delegates with a line `>> bot-name: task`. depth is
capped, every handoff lands in bot_messages, and every outward write
still stops at your approval card. schedule a bot with a schedules row
whose text is `bot:<name>: <task>`.
